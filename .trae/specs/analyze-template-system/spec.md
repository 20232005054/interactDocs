# Analyze Template System Spec

## Why
用户希望深入了解后端项目结构，特别是项目的模板系统是如何工作的，以便为后续的开发、文档编写、系统维护或架构扩展提供坚实的理解基础。

## What Changes
- 分析后端代码库中与模板系统相关的核心文件、数据库模型和服务模块。
- 总结模板系统的分层架构，包括主模板、核心信息模板、摘要与结构模板以及 AI 提示词模板。
- 梳理基于模板的文档自动化生成工作流。
- 产出详细的结构化分析报告。

## Impact
- Affected specs: 无（这是一个只读性质的代码库分析任务）
- Affected code: 无（不修改任何现有代码）

## ADDED Requirements
### Requirement: 模板系统架构梳理与总结
系统（Agent）需要查阅代码库，提取出模板系统的核心运作机制，并以易于理解的方式向用户展示。

#### Scenario: Success case
- **WHEN** 任务执行完毕后
- **THEN** 用户能够获得一份包含核心文件路径、数据流向和系统各层级职责说明的详细总结。
